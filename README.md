# HiFi Working Transmisi – PLN Operasi Sistem Hub

Repositori terpusat untuk portofolio desain, prototipe, dan aplikasi HiFi PLN Operasi Sistem.

## 📁 Daftar Proyek
1. **[Peta Kerawanan Sistem & Subsistem 2026](./peta-kerawanan/)** ([Live Demo](./peta-kerawanan/dist/index.html))
   - Dashboard enterprise peta kerawanan & keandalan sistem transmisi 500 kV/150 kV.
   - 4-Level drill-down (Peta Nasional, Jamali, UP2B, Subsistem) + SLD Interaktif React Flow (MANTAPS Style).
2. **[ROTS – Rencana Operasi Tahunan Semester](./rots-pln-transmisi/)**
   - Dashboard monitoring rencana operasi sistem tenaga listrik semesteran.
   - Analisis Neraca Daya, Outage (Planned/Unplanned), Beban Puncak (BP), dan Cadangan Daya (CAD).
3. **[Dashboard Proteksi Transmisi](./dashboard_proteksi2.html)**
   - Dashboard monitoring sistem proteksi transmisi dan rele kelistrikan.
4. **[Defense Scheme Transmisi](./Defense_Scheme_Complete_Readable_v2.html)**
   - Desain skema pertahanan sistem kelistrikan terpadu.
