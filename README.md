# HiFi Working Transmisi – PLN Operasi Sistem Hub

Repositori terpusat untuk portofolio desain, prototipe, dan aplikasi HiFi PLN Operasi Sistem.

## 📁 Daftar Proyek
1. **[ROTS – Rencana Operasi Tahunan Semester](./rots-pln-transmisi/)**
   - Dashboard monitoring rencana operasi sistem tenaga listrik semesteran.
   - Analisis Neraca Daya, Outage (Planned/Unplanned), Beban Puncak (BP), dan Cadangan Daya (CAD).
2. **[Dashboard Proteksi Transmisi](./dashboard_proteksi2.html)**
   - Dashboard monitoring sistem proteksi transmisi dan rele kelistrikan.
3. **[Defense Scheme Transmisi](./Defense_Scheme_Complete_Readable_v2.html)**
   - Desain skema pertahanan sistem kelistrikan terpadu.
